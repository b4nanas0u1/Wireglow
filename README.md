# Wireglow

**Русский** | [English](README_en.md)

Wireglow — настольный клиент для управления сетевыми подключениями на основе ядер [free-turn-proxy](https://github.com/hackdiaz-dev/free-turn-proxy) и [mihomo](https://github.com/MetaCubeX/mihomo). Приложение объединяет профили подключения, управление локальным прокси и состояние сетевой сессии в графическом интерфейсе.

## Назначение

Проект предназначен для работы с сетевой инфраструктурой, к которой пользователь имеет разрешённый доступ, а также для разработки и проверки интеграции сетевых компонентов. Параметры удалённого подключения задаются импортируемым пользователем профилем.

Использование приложения должно соответствовать применимому законодательству и правилам владельцев задействованных сетей и сервисов.

## Статус

Проект находится в активной разработке.

## Возможности клиента

- Импорт профилей free-turn-proxy, их хранение и редактирование отдельных параметров.
- Подключение и отключение сессии, отображение её состояния и задержки.
- Локальный HTTP/SOCKS-прокси и переключение в режим системного прокси.
- Настройка локальных адресов и портов сетевых компонентов.
- Интерфейс на русском и английском языках.

## Планы

- TUN-режим для подключения без настройки прокси в приложениях.
- Правила маршрутизации: выбранные сервисы напрямую, остальной трафик через подключение.
- Загрузка версий free-turn-proxy с GitHub и выбор используемой версии.
